================================================================================
              TOUCH WINDOW AI AGENTS - QUICK START GUIDE
================================================================================

This guide will help you run the AI agents with a web dashboard in under 5 minutes.

================================================================================
OPTION 1: DOCKER WITH DASHBOARD (RECOMMENDED - EASIEST)
================================================================================

REQUIREMENTS:
- Docker Desktop installed (https://www.docker.com/products/docker-desktop/)

STEPS:

1. Open a terminal (Command Prompt, PowerShell, or Terminal)

2. Clone the repository:
   git clone https://github.com/Dsarikrishna/touchwindowagents.git

3. Navigate to the folder:
   cd touchwindowagents

4. Start everything with one command:
   docker-compose up

5. Wait for the services to start (about 1-2 minutes)

6. Open your browser and go to:
   
   *** WEB DASHBOARD: http://localhost:8501 ***
   
   This is the user-friendly interface where you can:
   - See all agents and their status
   - Trigger agents with one click
   - Monitor agent activity

7. To stop everything:
   Press Ctrl+C or run: docker-compose down

================================================================================
OPTION 2: GITHUB CODESPACES (CLOUD - NO INSTALL NEEDED)
================================================================================

REQUIREMENTS:
- GitHub account (free)

STEPS:

1. Go to: https://github.com/Dsarikrishna/touchwindowagents

2. Click the green "Code" button

3. Click "Create codespace on main"

4. Wait 2-3 minutes for setup

5. In the terminal, run both commands:
   
   Terminal 1 (Agents):
   func start
   
   Terminal 2 (Dashboard):
   streamlit run dashboard.py --server.port 8501

6. Click the "Ports" tab and open port 8501 to see the dashboard

================================================================================
OPTION 3: LOCAL WINDOWS (WITHOUT DOCKER)
================================================================================

REQUIREMENTS:
- Python 3.12+
- Node.js

STEPS:

1. Install Azure Functions Core Tools:
   winget install Microsoft.Azure.FunctionsCoreTools

2. Install Azurite (storage emulator):
   npm install -g azurite

3. Clone the repository:
   git clone https://github.com/Dsarikrishna/touchwindowagents.git
   cd touchwindowagents

4. Install Python dependencies:
   pip install -r requirements.txt

5. Create local.settings.json file with this content:
   {
     "IsEncrypted": false,
     "Values": {
       "AzureWebJobsStorage": "UseDevelopmentStorage=true",
       "FUNCTIONS_WORKER_RUNTIME": "python"
     }
   }

6. Open TWO terminals:

   Terminal 1 - Run agents:
   Double-click start-local.bat
   
   Terminal 2 - Run dashboard:
   Double-click start-dashboard.bat

7. Open browser: http://localhost:8501

================================================================================
TROUBLESHOOTING
================================================================================

Problem: Dashboard shows "Offline" status
Solution: Make sure docker-compose up is running, or start-local.bat is running

Problem: Docker command not found
Solution: Install Docker Desktop from https://www.docker.com/products/docker-desktop/

Problem: Port 8501 already in use
Solution: Stop other Streamlit apps, or change port in docker-compose.yml

Problem: "Connection refused" errors
Solution: Wait a bit longer for services to start (can take 1-2 minutes)
